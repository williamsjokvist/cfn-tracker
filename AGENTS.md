# Agent guidelines

## Generated code

Never edit generated code by hand. Change the source it's generated from and regenerate it.

- `app/gui/wailsjs/**` is generated by Wails from the Go structs and handler methods bound in `app/main.go`. Regenerate it with `mise run bind` and commit the result.
- `mise run bind` builds and runs the app's `main()`, which applies database migrations to the local app data. If it fails on a migration error, the local database is from another version of the app. On macOS, regenerate with a throwaway home directory instead of editing the bindings:

  ```sh
  cd app && mise exec -- env HOME="$(mktemp -d)" GOPATH="$(go env GOPATH)" \
    GOMODCACHE="$(go env GOMODCACHE)" GOCACHE="$(go env GOCACHE)" wails generate module
  ```

## Tooling

This is a mise monorepo. The root `mise.toml` only marks the monorepo root. `app/mise.toml` (Go, Bun, Wails) and `web/mise.toml` (Bun) hold each project's tools and tasks. Run `mise tasks --all` to list them, and `mise run //app:<task>` or `//web:<task>` to run one from anywhere.
