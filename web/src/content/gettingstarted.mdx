# Getting Started
- Download the app for Windows or Mac
  <DownloadButton transition:persist/>
- On Mac, unzip the app and move it to Applications. The app isn't signed with an Apple Developer ID, so macOS will say it's damaged or can't be opened the first time. Either try to open it and click "Open Anyway" under System Settings → Privacy & Security, or run this in Terminal:
  ```sh
  xattr -dr com.apple.quarantine "/Applications/CFN Tracker.app"
  ```

## Tracking
- Extract the app wherever you want and launch it.
- Select either SF6 or Tekken 8.
- Input your user ID when prompted and press *Start*.

## Streaming
- Go to the Output screen, pick a theme and mark the stats you want to display.
- Click *Copy Browser Source Link* [*]
- Open OBS and add a Browser Source, paste the link as the source.

[*] Text files will also be generated in a folder called *results* in the same directory as the app. If you have a potato computer you can use these instead of the browser source 🥔
